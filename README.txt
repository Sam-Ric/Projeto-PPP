======= PROJETO PPP 2024 =======
Por Carlos Violas e Samuel Riça


A aplicação está dividida em 4 pastas:
    bin -> contém o ficheiro executável
    docs -> contém toda a documentação do programa
    lib -> contém todos os ficheiros .h
    src -> contém todos os ficheiros .c

Os ficheiros CMakeLists.txt e o Manual do Programador podem ser encontrados na pasta 'docs'.
